# Movie-Recommender-System

**Objective**: Enhance the movie discovery experience for users.

**Tools Used**:
Python: The primary programming language for building the system.
Pandas and NumPy: Utilized for data manipulation and analysis.
Streamlit: Created an interactive web interface for users to input preferences.
TMDB API: Accessed movie data (such as genres, ratings, and cast) from The Movie Database.
PyCharm: Used for developing the interactive web interface.
Jupyter Notebook: Used for exploratory data analysis and model development.

**Functionality**:
Recommends the top five similar movies based on user preferences.
Enables users to discover new movies aligned with their tastes.
